# API.md

Источник правды по эндпоинтам. Фронт и бэк договариваются здесь **до** того,
как что-то написано в коде. Если нужного эндпоинта в этом файле нет —
сначала описываем и согласуем, потом пишем.

Порядок изменений: отдельная ветка → PR с правкой `API.md` → согласование →
только после этого код.

## Соглашения

- Базовый адрес в разработке: `http://localhost:8000`
- Формат: JSON, кодировка UTF-8
- Аутентификация: заголовок `Authorization: Bearer <token>`
- Даты и время: ISO 8601, UTC (`2026-09-28T10:00:00Z`)
- Ошибки: тело `{"detail": "текст ошибки"}`

### Коды ответов

| Код | Когда |
|---|---|
| 200 | Успех |
| 201 | Создан объект |
| 204 | Успех, тела нет (удаление) |
| 400 | Кривой запрос |
| 401 | Нет токена или он протух |
| 403 | Токен есть, но объект чужой |
| 404 | Объекта нет |
| 422 | Не прошла валидация тела запроса |

## Служебные

### `GET /health`

Проверка, что приложение живо. Авторизация не нужна.

Ответ `200`:

```json
{"status": "ok"}
```

### `GET /health/db`

То же, плюс проверка соединения с базой. Авторизация не нужна.

Ответ `200`:

```json
{"status": "ok", "db": "ok"}
```
