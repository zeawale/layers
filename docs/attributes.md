# Справочник атрибутов одежды

Ответственная: Настя. Дедлайн первой версии — 28 сентября.

Это единственный источник названий. Их же используют схема базы, API и фронтенд — если название меняется, оно меняется здесь, и дальше по всем трём.

Формат: у каждого атрибута — машинное имя (латиница, snake_case), название для интерфейса (по-русски) и список допустимых значений с их машинными именами.

## Шаблон

`machine_name` — Название в интерфейсе

Тип: список значений / число / логическое. Зачем нужен движку подбора: одна строка.

| Значение | Название в интерфейсе | Комментарий |
|---|---|---|
| value_one | Значение один | |

## category — Категория

Тип: список значений. Зачем нужен движку подбора: определяет, к какой части образа относится вещь — по этому полю собирается комплект.

| Значение | Название в интерфейсе | Комментарий |
|---|---|---|
| top | Верх | футболки, рубашки, свитера, худи и другая одежда выше пояса |
| bottom | Низ | джинсы, брюки, шорты, юбки |
| outerwear | Верхняя одежда | куртки, пальто, пуховики, дождевики |
| footwear | Обувь | кроссовки, ботинки, сапоги |
| accessory | Аксессуары | шапки, шарфы, перчатки, ремни, сумки |

## color — Цвет

Тип: список значений. Зачем нужен движку подбора: сочетаемость по цвету в комплекте. Цвет определяется автоматически по фото (rembg + k-means), поэтому значения — крупные группы, в которые можно попасть из RGB-кластера, а не точные оттенки.

## warmth — Теплота

Тип: число (1–5). Зачем нужен движку подбора: подбирает нужное количество и теплоту слоёв под температуру на улице.

| Значение | Название в интерфейсе | Комментарий |
|---|---|---|
| 1 | Очень лёгкая | футболка, тонкая рубашка |
| 2 | Лёгкая | лонгслив, тонкий свитер |
| 3 | Средняя | плотный свитер, худи |
| 4 | Тёплая | демисезонная куртка, кардиган на флисе |
| 5 | Очень тёплая | пуховик, зимнее пальто |
