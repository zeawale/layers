# Справочник атрибутов одежды

Ответственная: Настя. Дедлайн первой версии — 28 сентября.

Это единственный источник названий. Их же используют схема базы, API и
фронтенд — если название меняется, оно меняется здесь, и дальше по всем трём.

Формат: у каждого атрибута — машинное имя (латиница, snake_case), название
для интерфейса (по-русски) и список допустимых значений с их машинными именами.

## Шаблон

### `machine_name` — Название в интерфейсе

Тип: список значений / число / логическое.
Зачем нужен движку подбора: одна строка.

| Значение | Название в интерфейсе | Комментарий |
|---|---|---|
